# ⚡ TicTacToe Game

A sleek and modern implementation of the classic TicTacToe game with multiple AI difficulty levels and a beautiful responsive design.

## 🎮 Features

- **Multiple Game Modes:**
  - Player vs Player
  - Player vs AI (Easy)
  - Player vs AI (Medium)
  - Player vs AI (Unbeatable)

- **Modern UI/UX:**
  - Smooth animations
  - Hover effects
  - Responsive design
  - Beautiful gradient background
  - Glass-morphism effects

- **Smart AI Implementation:**
  - Easy mode: Random moves
  - Medium mode: Mix of random and strategic moves
  - Unbeatable mode: Minimax algorithm

## 🎯 Game Rules

The game is played on a 3x3 grid
Players take turns placing X's and O's
First player to get 3 in a row (horizontally, vertically, or diagonally) wins
If no player gets 3 in a row and the grid is full, the game is a draw

## 🎨 Customization
